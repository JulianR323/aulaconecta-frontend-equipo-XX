AulaConecta 

 Descripción del Proyecto
AulaConecta es una aplicación móvil web diseñada para la comunidad SENA. Su objetivo es centralizar la información de actividades, fechas de entrega, calificaciones y avisos o comunicados en un solo canal accesible desde dispositivos móviles.

Problema que resuelve: La dispersión de información por múltiples canales lo que ocasiona confusiones, entregas tardías y dificultad para la comunicacion asertiva .
Objetivo del Front-end: Diseñar e implementar una interfaz móvil intuitiva, accesible y fácil de usar tanto para aprendices como para instructores.

 Alcance Inicial 
1. Inicio de Sesión: Autenticación rápida con correo institucional o Google y recuperación de clave.
2. Página Principal: Resumen del día, horario del trimestre, comunicados recientes y alertas de tareas por vencer.
3. Lista de Actividades: Gestión de tareas organizadas por vencimiento, estado, complejidad y filtros por competencia.
4. Detalle de una Actividad: Subida de entregas, material de apoyo, anotaciones personales y panel de observaciones.
5. Consulta del Progreso y Calendario de RAPs: Indicadores de cumplimiento académico y guiaas diaria de clases por RAP.
6. Comunicados:  novedades publicadas por instructores.

Criterios de Calidad para Fusionar a main
1. La funcionalidad debe responder a una Historia de Usuario (HU) definida.
2. La interfaz funciona de forma cómoda desde un celular.
3. Cada pantalla incluye botones de navegación/regreso para evitar bloqueos.
4. Código y documentación revisados por al menos un compañero.
5. Historial claro y estructurado.
