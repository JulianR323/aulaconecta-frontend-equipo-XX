 Registro de comandos
 1. git commit
¿Qué nodo nuevo apareció y dónde quedó apuntando la rama?
 Apareció un nuevo nodo o commit justo debajo del último en el que estábamos parados y la rama en la que nos encontrábamos se movió automáticamente para quedar apuntando al nuevo commit

 2. git branch
¿Qué se creó y sobre qué commit quedó ubicado?
  Se creó una nueva rama y quedó ubicada exactamente sobre el mismo commit en el que nos encontrábamos parados en ese momento

3. git checkout
¿Qué cambió al moverse a otra rama?
  Cambió la rama activa en la que estamos trabajando los nuevos commits o cambios que hagamos a partir de ese momento se guardarán en esa nueva rama y no en la anterior

 4. git merge
¿Qué historias de trabajo quedaron integradas?
  Quedaron unidas e integradas las historias de dos ramas distintas en un nuevo commit reuniendo todos los avances en un solo lugar
